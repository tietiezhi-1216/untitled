# 无线麦

无线麦 1.0.0 适用于 Untitled 0.13.51+、macOS 14+。它把一台 Mac 的实体麦克风传给同一局域网内的另一台 Mac。接收端的会议、录音等应用可把 **Untitled Microphone** 当作输入。两台 Mac 可以各自选择发送、接收或同时启用两者。插件使用自己的连接和配对码。

## 安装与使用

1. 在两台 Mac 安装支持无线麦的 Untitled。在「插件商店 → 从 ZIP 安装」选择无线麦插件包，再从侧栏「我的插件」打开「无线麦」。
2. 接收端需显式安装一次虚拟麦克风。点击「复制安装命令」，在终端执行复制的命令，再重启接收端。发送端只需要实体麦克风。
3. 在一台 Mac 的「配对设备」中生成并复制配对码，在另一台 Mac 粘贴并保存。两台都点「启动无线麦」，然后只在其中一台点击对端旁的「连接」。发现列表为空时可填入另一台 Mac 的 IP 地址或主机名。连接失败时请核对 macOS 的「本地网络」授权与两端配对码。
4. 发送端选中实体麦克风，开启「允许发送本机麦克风」。接收端开启「在这台 Mac 使用对端麦克风」，并在目标应用中选择 **Untitled Microphone**。当目标应用开始读取时，发送端检查麦克风权限并开始采集。若宿主打开权限管理，完成授权后手动重新开启发送。
5. 用插件内或菜单栏中的「停止无线麦」释放设备并关闭网络。会议软件在静音时也可能保持麦克风输入打开，需要中止采集时请关闭发送或停止无线麦。

驱动随完整应用包提供，也可按 [HAL 驱动说明](../peripheral-sharing/Tools/SharingMicrophone/README.md) 安装或卸载。插件从 ZIP 安装、启用和打开时均不会启动网络、采集麦克风或安装驱动。接收需要系统本地网络许可，发送另外需要麦克风权限。虚拟驱动的安装是接收端用户发起的管理员操作，应用不会更改系统默认音频设备。

## 数据与停止行为

- 配对码是 256 位随机凭据，保存在各自 Mac 的钥匙串。输入设备选择存在本机偏好中。解绑从插件的「配对设备」执行。重新安装插件可继续使用已有配对；连接与发送、接收开关不会在下次启动自动恢复。
- 使用独立 Bonjour 服务和 TCP 48480，传输采用已有的 TLS 1.2 PSK / AES-GCM 实现，麦克风连接使用独立派生密钥。配对码只提供给可信设备。此 TLS 模式没有前向保密。音频发送给已配对 Mac，不经过云服务或写入录音文件。
- 断开连接、超时、锁屏或睡眠、停用、更新、卸载和退出均释放采集和虚拟输入的输出流。主动断开会保留已启动的设备发现；停止无线麦会一起关闭。在权限或设备失效后，检查并手动重新开启相应功能。
- ZIP 包只有清单、说明和仓库许可证。原生代码随宿主构建，HAL 驱动使用 [libASPL 及其随附许可](../peripheral-sharing/Tools/SharingMicrophone/README.md#构建)。

## 性能与资源

正常格式为单声道 48 kHz Float32 PCM，每包 960 采样（20 ms，3,840 字节）。每个会话只连接一台对端，每个方向仅有一个音频设备。采集邮箱最多留六包，拥塞时丢弃积压的实时帧；网络在途音频触及约 32 KiB 时开始丢帧；接收待播放队列限制在 9,600 帧（200 ms）。未启动时没有插件定时器；启动设备发现后只在认证连接上每秒维护会话，每 20 ms 的音频发送定时器只在实际采集时运行。

在本机使用两个隔离的插件实例、TLS 回环和虚拟的音频输入输出，可以验证 960 帧数据的按需传输、十轮采集启停和资源释放，以及权限拒绝、撤销和停用后的停止。复现命令为 `swift test --no-parallel --filter WirelessMicrophoneTests`。在 Apple M4、16 GB、macOS 27.0.1 的命令行测试中，三项焦点测试通过，十轮均释放了采集和输出流。真实双机的 HAL 输入、设备切换、睡眠恢复、端到端延迟、系统音频进程与长时间能耗仍待测量。
