# 语音输入

v1.2.16，macOS 14+、Untitled **0.13.50+** 的原生语音听写插件。Swift 自行实现豆包网页游客初始化、VoiceGenie WebSocket 与 protobuf 消息，不运行 Python 桥接器、不注入微信或豆包客户端。

## 使用

1. 直接按听写快捷键说话，在桌面、浏览网页或没点输入框时也能开始。草稿只显示在屏幕底部的气泡，不改输入框或剪贴板。录音需要麦克风权限，无需安装输入法或切换双拼。
2. 想直接上屏，就在收到定稿前点好目标输入框；松开按住键（或再按一次切换键）后，插件会在豆包定稿时查看**当时的焦点**。能安全写入，就在光标处插入一次（有选区则替换选区），不动剪贴板。没有可写焦点或辅助功能授权，就把完整定稿复制到本机剪贴板，气泡会提示。若编辑器未确认写入，也只复制、不重发，粘贴前请先核对。取消或没收到定稿均不自动复制。
3. 「识别历史」按完成时间从新到旧显示，点击一条记录旁的「复制」可复制完整文字。默认在本机保留最近 **100 条**，重启仍可查看。「语音输入设置 → 识别历史」可改为 0–500 条；保存较小的上限会立即删除最早的记录，0 表示不保留。也可单独清空历史。

默认按键均可在右上角「快捷键」中修改：

| 操作 | 默认快捷键 | 行为 |
| --- | --- | --- |
| 切换听写 | **⌃⌥空格** | 按一下开始 / 再按一下结束 |
| 按住说话 | **右 ⌘** | 单独按住约 0.2 秒，浮条出现后说话；松开定稿 |
| 取消 | **⌃⌥Esc** | 放弃本次听写，不提交草稿 |

Untitled **0.13.47** 起，听写连接、录音或等待定稿时可直接按 **Esc** 取消；按住右 ⌘ 说话时不用先松键。取消停止采集，不提交、不自动复制、不新增历史。开始投递定稿后不再拦截 Esc，也不会撤销已发出的文字。空闲时 Esc 仍交给当前应用，原有自定义取消键不变；系统、其他绑定或键鼠共享已占用时，仍可用面板「取消」。

右 ⌘ 是空格右边的 Command 键。轻点不录音，左 ⌘ 不触发；右 ⌘C / ⌘V 等组合键仍交给前台应用。已开始听写后再把右 ⌘ 用作组合键，会取消本次听写，不提交草稿。无需打开键盘优先模式。升级仅替换原来未改过的「按住说话」默认键；已自定义、清除、停用或删除的绑定不会恢复，右 ⌘ 已被其他操作占用时也不抢占。

气泡固定在开始听写的屏幕底部正中。Untitled **0.13.50** 起，刚开始是 88 × 38 pt 的彩色波形胶囊；第一份草稿到来时，声柱渐隐、玻璃透出独立漂移的多色光团，留下居中的单行字幕。胶囊增高到 48 pt，随文字从中间向两侧变宽，保留全圆角，最宽 296 pt；同一次听写里的短修订不会让外框来回收缩。短句居中，写满后旧字平滑向左移，最新的字留在右侧，停顿后静止，不换行也不循环播放。新字按阅读顺序逐个从透明变清楚，即使一次收到整句也不整组出现。改写只对新字启动淡入，已经出现的字不重闪；长句只裁剪预览，不截短定稿。macOS 26 及以上使用原生 Liquid Glass，较早系统使用系统浮层材质。开「减弱动态效果」直接显字，开「降低透明度」则使用不透明底色。气泡不抢焦点，鼠标可穿透；用原快捷键结束或取消。连接就绪前松开按住键也会提交已录下的短句；取消则不再启动麦克风。没有语音定稿就不会写入或保存历史。

定稿时背景停止漂移，关闭浮条或取消时结束全部绘制任务。「减弱动态效果」直接展开，使用静态色光；「降低透明度」使用原有不透明底板，不叠加透色光晕。尚未升级宿主时可继续使用 [1.2.15](https://github.com/tietiezhi-1216/untitled/releases/tag/v0.13.49)。[离屏测试与绘制开销](../../docs/DEVELOPMENT.md#构建)。

如果曾在 1.2.5 手动安装过「Untitled 实时听写」，本版不会选择或卸载它，也不会更改键盘设置。保留或移除旧输入源不影响气泡预览。

## 麦克风选择与采集诊断

- 面板 / 设置提供本机输入设备选择。默认跟随系统默认输入，但每次开始都会解析并明确绑定该设备 UID；选择设备只更改本插件偏好，不修改系统默认设备，也不提前录音。
- 已选择的设备断开时明确拒绝，不偷偷换成另一支麦克风；在麦克风下拉菜单中选择「刷新设备列表」，然后重新选择。列表最多 128 个设备，只在页面显示、手动刷新和主动开始时查询，不保留后台设备监听。
- 采集来自运行 Untitled 的这台 Mac。对着手机或另一台 Mac 说话，声音不会自动传入；虚拟 / 聚合设备会明确标注，需用户已有相应路由。
- 语音输入设置中的「采集诊断」可展开查看实际输入名称、PCM 字节数、音频回调次数、原始 RMS 音量峰值 dBFS 和 ASR 更新次数。诊断不包含声音或识别内容；这些计数用于区分「无回调」「纯静音」和「有信号但没有识别」。
- 原先只显示最近一个 20 ms 帧的音量，可能被下一个静音帧覆盖；现在保留每次 50 ms 合并读取之间的峰值。启动后 5 秒仍没有任何音频帧会停止并提示恢复路径；正常有帧的静音不会被当成队列失败。
- 输入队列显式检查协商的 16 kHz 单声道 PCM16 格式和缓冲重入错误，停止 / 销毁时同步等待回调；不以 AudioQueueStart 成功码代替已采到声音。

## 实时识别与最终整理

音频通过 16 kHz、单声道、PCM16 实时发送。使用网页端的 **two-pass ASR** 配置：录音中接收 streaming hypotheses，结束后等待 `ASREnded` 和整段定稿。整段模式下，`FinishSession` 负责收尾，它的回执丢失不影响已经确认的文字。若回执先于定稿到达，继续等待真正的定稿；若上游只返回中间稿，则明确提示未定稿。旧式分段流仍需等待会话结束回执，不能把前半句当作整段。

同一段音频会返回多次修订。当前服务会在同一条消息中给出整段转写和带时间或序号的分段明细。插件只用整段转写更新草稿，等**整段**定稿后才提交和保存；不会把分段明细或上一版草稿追加到定稿里。确实说了两遍的话仍保留两遍，不根据文字相似度删词。升级不会改写以前的识别历史。

**实时标点限制**：同一 14.81 秒合成样本的三轮对比（原配置、关闭 `enable_trim_punctuation`、省略 `last_post_process`）均得到 35 次非空实时更新，实时稿中 0 次含标点；结束后最终稿包含 9 个标点、67 个 UTF-16 单元。服务的转写内容只在 `text` 字段中，没有被本插件丢掉的另一份带标点实时文字。试验参数没有改善，生产配置保持原样，不用本地规则猜标点。

停止录音后仍可在气泡看到修订，但不向输入框提交。只有 `finish()` 返回的权威定稿可以触发一次提交。目标若忽略或截断写入，仅回读确认，不拆分重发、不回删。单个输入事件不等于跨应用原子事务。

松开「按住说话」或再按一次切换键后，请等最终结果写入再发送。「正在定稿」表示还在等豆包，「正在更新输入框」表示已收到定稿、正在核对写入。输入框一直不确认时不会反复写入，完整定稿会复制到剪贴板；如果豆包的定稿本身没有标点，插件不会自行补句号。录音中可以切换目标。只在收到定稿、已经选定目的地之后再次切换或改动选区 / 原文，才会中止向这个目的地的投递，不会转投下一处。当前不能宣称支持逐字即时标点。

最终结果由豆包 ASR 处理标点与数字规范化，并可能纠正中间识别错误。例如合成样本的「明天下午三点」在最终文本中变为「明天下午 3 点」。**这不等于额外大模型润色**：本轮合成样本中的「嗯、那个、然后然后」仍会保留，不能保证删除口头语、纠正事实、改写或总结；插件不会将文本发送给另一模型。

这是非官方网页接口，并非火山引擎开放 API。网页结构、应用标识、模型路由、限额和服务可用性可能变化；无需登录或账号密钥不代表官方承诺免费、无限量或长期兼容。失败不自动更换身份重试，不静默重传录音。

## 输入安全与兼容边界

- 启动、录音和等待定稿期间不读输入框。只在收到非空定稿后静默检查辅助功能，再绑定此时的前台应用、可编辑焦点、原文和 UTF-16 选区。密码框、安全输入、只读区域、不支持的控件和宿主管理面板均不投递按键，而是复制这次的听写定稿，不复制字段内容。
- 在捕获目的地后失焦、手动编辑、移动光标或失去插入授权时停止自动写入。只在仍能确认归属时用一次进程定向的 Unicode 文字事件提交**完整定稿**，不模拟粘贴、选区移动或删除，不重写用户整框。单次输入最长 32,768 UTF-16 单元。AX IPC 由会话内串行 worker 执行；发出以后最多回读等待 1.5 秒，不把成功发送等同于确认上屏。
- 换行、Tab、Esc 等控制字符写入时转换为空格，避免触发发送或导航快捷键。原始识别结果仍可在面板查看和手动复制。
- 长串、选区和具体编辑器仍需用户实际验证；不宣称兼容所有 Electron、浏览器或微信输入框。写入失败不会改向新焦点，也不会自动重试。
- 为校验范围，会暂时读取焦点输入框的文本（最多 131,072 UTF-16 单元），不会把原文、周围文档或其他窗口内容发给豆包。该快照随会话结束释放。
- 定稿提交前取消或停用不写入任何文字。如果最终事件已经发出，不再试图回撤或重发。重新导入插件不会提示空闲听写已停止；若正有听写会话，才会中断并保留已经识别的文字。

跨应用自动化不是原子事务；某些应用的 AX 实现可能延迟或拒绝修改。本实现遇到不一致即停止，不宣称兼容所有编辑器。

## 数据、网络与权限

插件 ID：`com.untitled.doubao-speech-input`。听写需要 `system.microphone`；`system.accessibility` 对直接插入是可选能力，未授权就复制，投递时不弹授权或抢焦点。选择设备、查看和复制历史不申请这两项权限。普通键盘组合使用 Carbon。独立右 ⌘ 通过宿主辅助功能通道识别，不要求开启键盘优先模式，不把其他应用的按键或文字交给插件。

仅在显式听写时访问：

- `https://www.doubao.com/chat/`：取得服务端正常分配的新游客设备标识。
- `wss://frontier-audio-web-ws.doubao.com/api/v2/sami/voicegenie`：发送麦克风音频、接收转写。

不读取 Chrome / Safari / Edge 登录资料，不保存或转发首页 Cookie，不持久保存游客设备标识；WebSocket 不携带账号登录凭据。公开网页应用标识不是个人 API Key，因此本版没有密钥设置。

不保存录音、输入框原文或中间草稿，也不把识别文字写入日志。只将一次成功定稿的文字、记录 ID 和时间保存在本机；上屏失败但已定稿的文字仍可复制。没有定稿或在定稿前取消的会话不产生历史。只有无法确认直接插入的定稿或手动复制才写剪贴板。自动复制仅写本机的完整纯文本，标记为自动生成，不读取或保存之前的剪贴板内容，不模拟 ⌘V。若剪贴板也失败，仍可在面板手动复制。

历史和保留条数位于宿主应用支持目录的 `Plugins/Preferences/<plugin-id>.dictation.history/records.sqlite3`。每个插件独立，限额和淘汰在同一事务中提交。列表只读每条最多 160 个 Unicode 标量的摘要，复制时读取该条全文；单条上限沿用 ASR 的 32,768 UTF-16 单元。数据库只在读取、定稿、修改上限或清空时打开，串行操作后关闭，不轮询。

麦克风和时长仍使用 `Plugins/Preferences/<plugin-id>.dictation.json`；升级忽略旧实验 / 实时开关，保留设备、时长、热键和插件启停状态。卸载删除本插件的偏好和历史，停用保留历史。

## 性能与资源预算

- 每个插件实例最多 **1 个录音 / 网络会话**；不并发录音，不加载本地模型。
- 默认每次 **180 秒**，可选择 30 / 60 / 180 / 300 秒；到达上限自动结束录音并请求定稿。
- AudioQueue 使用 3 个 20 ms 输入缓冲区，回调只向锁保护邮箱写 PCM 和音量，不在回调里联网或创建 Task。
- 连接期间暂存最多 **320,000 字节（10 秒 PCM）**，就绪后按 100 ms 分片清空，并把发送邮箱收紧到 **64,000 字节（2 秒 PCM）**。超预算会停止并报错，不无限排队，也不静默丢音频；不为整场会话保留录音，不写录音文件。
- 首页最多 **2 MiB**，单条消息最多 **256 KiB**，听写文字最多 **32,768 UTF-16 单元**；仅保留 64 个近期消息 ID 去重。连接、发送和结束阶段有 15 秒操作看门狗。从用户结束到取得定稿另有 18 秒总预算（含尾音频发送）；已取得定稿后，输入框确认另计最多 4 秒。两段超时分别处理，只有已确认的定稿才可能进入历史。
- Esc 仅在一次可取消的会话内借用至多两个普通 Carbon 键位，不创建键盘事件 tap，不新增权限、按键采样或轮询；结束、取消、停用和退出释放。快捷键全局暂停或正在录制绑定时不注册。
- 仅活动会话有 50 ms 合并发送循环、1 秒麦克风权限检查 / 网络看门狗；草稿只替换气泡的有界文字预览，每次听写至多一次最终文字写入。音量条由实际音量驱动，不设置空闲动画时钟。
- 正常完成、取消、断网、权限失效、停用、升级、卸载、退出和对象销毁都会停止并同步销毁 AudioQueue、取消 Task、关闭 WebSocket、清理页面会话与浮条。空闲不保留设备、网络连接或轮询任务。需要提示剪贴板结果时复用原来的非激活窗口显示静态回执，约 2 秒自动关闭；新会话或停用立即关闭。诊断只增加有界计数和峰值，不另存音频；停止后保留这一份统计直到下次会话。

### 1.2.15 单行滚动字幕

保留 296 pt 宽度、15.5 pt 字号和约 9 pt 边距，展开高度从 84 降到 62 pt。短句居中，超过一行时只移动字幕，气泡和 31 个音柱不跟着移动。滚动按最新识别修订更新，不循环、不排队重播旧草稿；打开「减弱动态效果」立即显示最新一行。滚出屏幕的字只离开预览，定稿和历史仍是全文。

离屏浅／深色实绘检查了首次整句、逐包追加、滚动中途改稿、暂停再续、重复字滚过 96 个字形簇、半角混排和组合 emoji。实测同一彩色字形连续向左，静止后不循环，离屏定稿仍是全文。显示侧最多缓存 96 个完整字形簇、640 个 UTF-16 单元和同规模的位置表，不缓存历史字幕帧。优化编译的同一组合成 4,000 次排版更新，三轮中位数约 714 ms（旧版两行约 1,806 ms）；每轮 10/10 次拆窗后回收。这里只计排版更新，不是整机渲染或功耗；未用用户的麦克风或编辑器。

### 历史版本 1.2.14 的展开宽度与四边留白

展开态从 304 × 84 调为 296 × 84 pt，正文从 294 收到 278 pt。保留 15.5 pt 原字号、字距、两行预览和居中排版；本机连续全宽测试汉字一行从 19 个变为 18 个，混排按实际字宽自然换行，不删字也不强制断词。以同一条 9 pt 视觉边距为基准，纵向固定补偿音柱和字形自带的空白，不随停顿或标点移动。小胶囊、展开后的 31 个音柱位置以及逐字淡入节奏均保留。

浅色和深色离屏实绘中，同一段两行中文和同一组模拟音量下，四边可见留白从左／右／上／下约 6／6／14／9 pt 调到约 10／10／10／9 pt。短句和静音时仍自然留空，不改变外框来凑数。另检查了中英混排、组合 emoji、长句滚动和两端音柱；未使用真实麦克风或编辑器。

### 历史版本 1.2.13 的展开静音点列

点列的宽度随气泡展开，不随音量收缩。小胶囊安静时是 9 颗点，完全展开后是 31 颗；即使展开时没有新音量，或说完停顿，两端也有可见的圆点。再次开口，音柱从原先的位置升起。「减弱动态效果」使用相同跨度的静态点列，不启动波形时钟。

用合成输入离屏绘制浅色和深色气泡：小胶囊 9 点，无音量回调时展开到 31 点；发声、停顿、再发声、再停顿都保持 31 个分离位置。停顿后点列横跨约 230 pt，与发声时两端墨迹相差不超过 1 pt；波形时钟停止。未使用真实麦克风或编辑器。
