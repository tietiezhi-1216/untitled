# 截图

v1.8.4 需要 Untitled 0.12.28+；录屏和系统翻译需要 macOS 15+。
首次安装自动配置 [PixPin macOS 默认快捷键](https://pixpin.cn/docs/settings/shortcuts-actions)：

| 动作 | 默认快捷键 |
| --- | --- |
| 区域截图 | ⌃1 |
| 延时截图 | ⌥1 |
| 截图并复制 | ⌃⌥1 |
| 剪贴板贴图 | ⌃2 |
| 恢复最后关闭的贴图 | ⌃3 |
| 切换贴图组 | ⌃` |

⌃ 表示 Control。升级保留已有操作的自定义按键、清空、停用状态；后续升级不会恢复已删除的默认动作。与其他操作冲突时保留对方的绑定，新动作留空。可在「快捷键」页添加其他操作、暂停截图快捷键或恢复默认。恢复默认会重设默认动作，但保留自行添加的其他操作。普通注册模式的系统冲突会在操作旁显示；也可在应用通用设置中主动开启“优先响应所有插件快捷键”，由宿主在辅助功能授权后尝试优先匹配，不修改系统快捷键。安全输入及更早的系统过滤器仍可能限制优先级。

[编辑及贴图窗口快捷键](https://pixpin.cn/docs/settings/built-in-shortcuts)同样采用 PixPin 的 macOS 默认值，可在齿轮设置中展开「编辑与贴图快捷键」修改。包括编辑器中 Return 复制并关闭、⌘Y 重做、⇧⌘Z 清除标注、⇧C OCR 并复制、⌥Q 翻译、⇧1–⇧0 标注工具、⌘E 选择标注；文本输入时保留正常编辑按键。

## 使用

### 截图与选区

区域、窗口、鼠标所在屏幕的全屏截图；支持多显示器与 Retina。普通截图可跨屏框选，⌘A 先选择鼠标所在屏，再按一次选择全部屏幕。

与 PixPin 官方手册一致，截图模式有 **矩形、自由轮廓、折线、多窗口** 四种，不要与工具栏的矩形／折线「标注工具」混淆。默认矩形；按住 ⌃ 并按 Tab 临时显示切换面板，继续按 Tab 循环，松开 ⌃ 生效，⌃⇧Tab 反向切换；也可从信息栏模式菜单选择。自由截图松开闭合，折线逐点点击后回车／双击／右键闭合；多窗口可逐个加入，模式菜单提供增加／扣除区域。不规则选区外为透明像素。未选好范围时不显示多行配置表单。

普通区域／窗口截图松开后，只是形成可调整的选区：仍在同一次截图会话内，完整快照、遮罩和选区控制点保留，立即可标注，不跳到独立图片浮层，也不需要第二次「进入编辑」确认。拖边角改大小、在选区内拖动移动取样范围；点击外侧扩展范围，在外侧拖动可重新框选。扩选仍从原快照读取像素；裁剪预览和标注画布按实际源像素视口回放，不把向外取整后的裁剪图缩放回带小数的拖拽范围，避免松手后文字与细线变软。尺寸栏显示实际输出像素。已有标注锚定原屏幕位置，不随范围缩放或被裁切删除。截图原图从首帧起保持不透明且不缩放、不淡入淡出；周围独立矢量黑色遮罩只在截图开始和实际结束时做约 120ms 透明度渐变，悬停元素切换则只过渡遮罩孔与边框的几何，不改变截图像素；减少动态效果均跳过。截图准备、框选／标注、输出或鼠标截图启动期间，再按任何截图启动动作均静默忽略，不报错、不请求新权限、不重启当前范围；主动取消／完成后才可再次截图，正在录屏时的明确停止动作及历史／贴图操作仍可用。

选好范围后，上方显示紧凑尺寸／效果／模式入口，主工具条将全部 16 个标注工具直接平铺，同类相邻，按「形状、画笔、箭头与线条、文字、序号、马赛克与遮挡、擦除与修补、聚光与放大」分成八类，不再用分组小箭头隐藏子工具。默认主条为 806×40 点，独立图片编辑器为 828×40 点；沿用原保存顺序推导分组和组内顺序，不自动重排用户配置。宽度不足时只滚动工具区，复制、保存、贴图和关闭固定可见，键盘选中的具体工具会自动显露；无工具选中时不显示绘制选中态。点击尺寸才打开精确 X/Y/宽/高、比例和历史；选工具或标注后，下方显示按内容宽度计算的紧凑属性条，线型、填充、箭头、编号和马赛克等选择均为从上到下的单列下拉，每行一个实际图形预览，粗细／字号／圆角显示当前数值，颜色用色块及原生小色井；少见参数放在「更多样式」，不常驻说明表单。支持 ⇧ 正方形／水平垂直约束、⌥ 对称调整、方向键微移、⌘方向键扩大及 ⇧方向键收缩。窗口检测可直接选中窗口；已获辅助功能权限时可用 Tab 切换界面元素检测。⌥ 显示放大镜与辅助线，C 复制颜色，⌥C 复制坐标，F5 刷新画面。

元素检测优先选择鼠标当前位置可获得的最小有效元素框（至少 8 × 8 点），不会在检测间隔内或临时查询失败时反复退回外层大窗口。移出元素边界或点击时重新命中；候选限制在最前方可见窗口内，不选择被遮挡的后方小窗口。目标应用不公开元素或没有可用授权时按窗口检测。文字节点与消息留白切换时，若系统命中新指针的子树跳到了更大的容器，先以最后一次真实成功命中的位置重新获取实时节点，再沿实时父链核对原几何容器并在其内向下精确命中；不直接画缓存父框。仅以矩形／锚点作路由线索，布局变化、父框不匹配或预算不足时保留正常新命中路径；新鲜点击不使用历史路由。重查、父链与子树搜索仍共享同一节点／深度／时间预算，未增加全局 AX 缓存或空闲轮询。离开已知小元素后，失败或受限查询返回的粗祖先框不直接成为动画目标，缓存父框也不代替新目标绘制。查询保留获胜路径的有限矩形及受限状态；必要的 AX 父链读取与下降搜索共享原有节点、深度和时间预算，不保留 AX 对象或文字。检测不确定时暂留上一逻辑目标，80ms 确认一次、固定 240ms 逻辑期限到期再验证；移动或失败不续期，鼠标停住也会收敛，返回原有效叶框则取消该次离开状态。新鲜完整目标立即生效，始终不可用才回退窗口；期限不保证主线程繁忙时的实际显示时间。只保留当前窗口内至多 13 个路径矩形、一个可取消短任务，无空闲轮询；结束、重选、图像刷新成功提交、模式／区域操作切换和窗口分离会取消／失效。点击始终重新精确命中，不使用暂存或缓存矩形。未确认范围时，大框／小框及窗口悬停框之间有约 120ms 短过渡；快速连续切换从当前可见位置继续，同一目标不反复启动。点击即时重新命中并按真实范围确认，不使用动画中途的显示框；开始拖选、确认、标注或复杂轮廓时立即对齐精确范围。

「调整截图」和「选择／移动标注」不再作为常驻工具：无绘制工具选中时，命中标注或其控制点就选择、移动和编辑标注，拖空白选区就移动取样范围，选区边角始终优先调整范围。点击当前工具或按 Esc 退出绘制回到同一默认状态，不需要另切移动模式。范围变化仍保持标注的源像素位置，不把移动范围误作移动标注；已有选中标注可直接调整属性。矩形／椭圆、箭头／线、画笔／荧光笔、文字／水印、马赛克／遮挡、擦除／修补／智能擦除、聚光／放大等能力均保留在对应图标组；纹理修补与智能擦除仍显式进入独立编辑器。工具栏、尺寸栏与模式面板复用原生玻璃材质（减少透明度时降级）；标注和输出图标统一 28 点按钮、组内 2 点间距、组间 8 点留白，编辑与输出组以细线分隔，样式按钮保留固定位置。悬停显示高亮与约 350ms 后的名称／当前自定义快捷键提示，非激活截图面板也可用；按下、选中和不可用状态分别反馈，复制有轻量强调。图标菜单与普通按钮使用同一标签布局，「更多」三点以几何中心对齐 28 点悬停背景，不由原生弹出按钮重新栅格化或受字体基线影响；圆点以 3 点直径和 1.5 点间隙保持 12 点总宽度，避免 1× 屏幕上过细抗锯齿看起来像禁用。工具栏使用普通指针，框选与绘制用十字、文字用 I 形、移动范围用手形且拖动时握住，边角用对应方向缩放光标（macOS 15+ 原生对角缩放，旧系统角点退为十字）；不再用手形覆盖标注光标。点击工具栏按钮、间隙和边缘不重新框选或隐藏工具栏。双击选区、Return 或 ⌘C 执行复制并结束；复制失败、保存取消或出错仍留在原会话。贴图是明确的独立输出动作，不是选区松开后的默认状态。长截图和录屏保留专门的范围确认；「截图并复制」仍保留直接完成的动作含义。截图可加圆角、阴影或边框，「样式」中可调整圆角半径、阴影模糊／浓度／偏移、边框宽度与颜色，并选择以后截图沿用这些效果。单屏选区的矩形范围保留最近 100 条，可从「历史选区」恢复；历史范围不恢复自由轮廓或扣除蒙版，跨屏范围不写入单屏历史。录屏、长截图使用单屏矩形选区。

普通区域截图在同一遮罩会话内完成选区与标注，只在明确发起输出时写入历史，框选／调整／未输出即取消不会自动存图片。历史图片、剪贴板图片、全屏／重复区域的直接结果及用户从「更多」明确选择的独立图片编辑仍使用原位无边框浮层；纹理修补／智能擦除等高级编辑从明确入口进入该编辑器。点击复制按钮、按 ⌘C 或 Return，将当前含标注的图片写入剪贴板并关闭当前截图；复制或保存失败时保留状态供重试。文字输入中的 ⌘C 仍用于复制文字，普通贴图窗口不会因此自动关闭。截图保留当前可见的主窗口与贴图，只排除截图控制浮层；切换工具后可直接开始第一笔标注。延时截图支持 1–60 秒可取消倒计时。重复上次区域会检查原显示器是否连接并裁切到有效范围。

### 编辑与标注

无绘制工具选中时，命中标注就直接选择和移动标注，空白处拖动图片；按住 ⌥ 可临时拖动图片。独立图片的破坏性裁剪保留在「更多 → 裁剪图片」，与截图会话中始终可用的边角调整范围分开。工具条按当前工具显示样式；画完自动选中，端点、缩放、圆角和曲线控制点直接显示在图上。选中后按 Delete 删除、方向键微调（⇧ 为 10 像素）；⌘滚轮调整透明度。Esc 先退出当前绘制／选择，再关闭浮层。编辑状态下 Return 复制并关闭当前截图。工具按同类图标归组，可在「工具顺序」中拖动分组；同类工具全部直接显示，旧配置的组内顺序和快捷键不重置；旧版记住的子工具数据保留，但不再用于隐藏其他工具。

普通矩形截图在输出持久化时保存范围内的底图和可编辑标注，不把选区外的完整屏幕存入历史；非矩形蒙版或圆角／阴影／边框输出会合并标注，保留透明结果但不保留该次分层。独立图片编辑在复制、保存、关闭和退出时仍保留历史中的底图与标注，重新打开可继续修改。裁剪、整体旋转和修补会将当时的标注合并到图像；当前编辑会话仍可撤销，关闭后不保留完整撤销栈。

### 贴图

- **内容**：图片、纯文本、保留本地格式的 HTML 文本、颜色值、LaTeX 公式、文件卡片和系统支持的 GIF/APNG/WebP 动图。公式以随应用打包的 KaTeX 在本机渲染；复制 LaTeX 源码并贴图即可使用，不需要视觉模型。非图片文件显示文件名与图标，右键可在访达中定位源文件。
- **操作**：移动、滚轮／捏合缩放、透明度、锁定、置顶、阴影、鼠标穿透、分组、关闭后恢复、隐藏其他贴图、逐像素移动。支持多选后的批量关闭、恢复、移动到分组。图片可旋转、翻转、黑白、反色及调整亮度。
- **选字与拖出**：图片自动检测文字后可直接选中并复制；文本贴图可选字。⌥拖动忽略文字选择，⌘拖动把内容拖入其他应用。图片文字选择使用本地 OCR，识别顺序与准确性受图片内容影响。
- **缩略图和动图**：缩略图模式仅显示选定的一部分，可移动查看范围；动图支持播放／暂停、逐帧查看、调整速度。原始动图文件单独保存在本机，播放控制不改变原文件。
- **鼠标配置**：默认双击关闭、中键重置、⇧双击切换缩略图、⌘滚轮调整透明度；可在「贴图鼠标操作」中修改缩放、关闭、复制、拖出、多选等绑定。

「贴图」页管理分组与关闭历史。图像、位置和状态保存在本机，重启后恢复未关闭的贴图；删除文件卡片不会删除源文件。HTML 仅保留本地排版，不加载外部图片、脚本或远程样式。

### 长截图

选择纵向或横向，框定单屏内容区域，缓慢滚动，保留至少三分之一重叠。支持反向回滚、自动滚动、实时拼接预览、暂停／继续、重新开始、起止范围裁剪，以及「回滚时裁掉多余部分」。自动滚动需要辅助功能权限，手动滚动不需要。

无法匹配时不会盲目拼图；可回到最后成功拼接的位置继续。动态动画、无纹理背景、固定的大面积页头仍可能影响结果。横纵方向分别拼接，不是同时进行二维全景拼接。

单段达到 8000 万像素前会自动将当前段写入磁盘，再从上一视口继续下一段，保留接缝重叠，不再继续增大内存中的长图。面板显示当前分段编号；「分段导出」也可主动保存短图。完成后选择文件夹，导出按上到下／左到右编号的 PNG、`segments.json` 坐标与重叠索引以及阅读顺序说明。已封存段不接受回滚修改；起点／终点裁剪只作用于当前段。取消目录选择会保留暂停状态，导出失败可重试。「保留并关闭」或退出应用前会暂存当前段，可由「暂存目录」找回 PNG 和索引；成功导出后也保留暂存副本。

### 录屏与动图导出

macOS 15+ 可将单屏矩形区域录制为 H.264 MP4；帧率可选 5／16／24／30／60 fps，最长边可选 1280／1920／2560／4096。支持倒计时、暂停／继续、停止和重新录制。暂停通过分段记录并合并处理，暂停时间不进入最终视频。

可分别录制系统音频和麦克风，选择摄像头画中画（最多两台不同设备），记录鼠标及键盘事件。摄像头可移动、调整形状和大小。键盘记录仅在录屏期间启用，系统安全输入期间暂停。键鼠事件与音轨另存，回放时可修改效果及音量。

录制中可使用箭头、矩形、椭圆、序号、画笔及荧光笔，调整颜色与线宽，撤销或清空标注。默认鼠标操作穿透到被录制应用，选择工具后才进入绘制，右键可恢复屏幕操作；这些标注会写入视频画面。

回放支持起止时间裁剪、画面裁剪、0.2–2 倍速、画质、系统音频／麦克风音量，以及光标、点击和按键效果。可导出 MP4、GIF 或 WebP；动图帧率及尺寸可调，按倍速计算的结果最长 3 分钟，GIF/WebP 不包含声音。WebP 编码器随签名应用打包，用户无需另装命令行工具。

应用启动时可恢复意外中断前已经封存的录屏片段；最后尚未写完的片段不能保证恢复。正常退出应用会结束并保存录屏。导出成功前不替换目标文件。

### 识别、翻译、表格与文档

「识别／翻译」使用 Apple Vision 本地 OCR 和条码识别。系统翻译需要 macOS 15+，首次使用某语言可能需要下载系统语言模型。可编辑原文与译文，复制或导出；图片翻译按 OCR 文字行把译文放回对应位置。长译文无法容纳时会提示并保留文字结果，复杂背景及排版不保证还原。

表格预览先从本地 OCR 的文字位置生成基础结构，并在原图旁显示单元格位置。macOS 26+ 可手动「重新识别结构」，使用系统本地模型识别多个表格和合并单元格；识别期间可取消，未识别出表格时保留基础结果。可修改文本、合并／拆分单元格，并导出保留表格结构的 XLSX 或 DOCX。另支持 CSV、TXT、Markdown、LaTeX，以及原图附带可搜索文字层的 PDF；编辑器也可直接将图像导出为 PDF 页面。

公式识别、复杂内容的进一步识别可使用自行配置的视觉模型。未配置时，不提供本地数学公式转 LaTeX 的识别能力；已有 LaTeX 源码的贴图渲染仍可使用。Word 导出保留可编辑文本、标题和表格结构，不按像素还原复杂文档。

### 保存与全局鼠标

在「截图设置」中选择快速保存目录、格式、有损质量与文件名模板。支持 `{date}`、`{time}`、`{width}`、`{height}`、`{uuid}`；同名文件自动增加编号。可开启复制截图或贴图时自动导出。除随包编码器支持的 WebP 外，格式列表按当前系统 ImageIO 的编码能力显示，PNG 使用无损编码。静态 WebP 可调整有损质量，宽高各不超过 16383 像素；更大的图片可保存为 PNG／TIFF。

导出保留规则默认关闭；启用后仅清理本应用在目标目录中追踪且 SHA-256 未变化的旧导出文件，将其移到废纸篓，已修改或替换的文件会保留。导出文件与应用内部截图历史分别管理。

全局鼠标默认关闭。可添加多组「修饰键＋左／右／中键／侧键拖动」，每组独立启停，松开后编辑、复制、贴图、OCR 复制或快速保存。相同组合不能同时绑定两个启用的动作；已有单组设置会自动保留为第一组。未匹配的输入正常传递，点击或未形成有效截图的短拖动会还原为普通点击。忽略应用按 bundle ID 匹配，支持 `*`；所需权限仍由主应用管理。暂停截图快捷键或停用插件时，该入口也暂停。

## 权限与数据

系统授权统一位于主应用「应用设置 → 权限管理」。截图或录屏缺少权限时，由主应用说明用途并提供授权入口；点击授权后才出现 macOS 系统请求。授权后请重新执行，部分系统权限更改可能需要重启应用。

麦克风、画中画和按键显示是本插件的业务选项；仅在实际录制且对应选项开启时，向宿主请求麦克风、摄像头或输入监控。自动滚动或全局鼠标需要辅助功能，手动滚动不需要；元素检测仅使用已经获得的辅助功能权限。录制扩展和全局鼠标默认关闭。权限请求由插件交给宿主，系统授权入口保持集中。

历史记录位于 Application Support/com.untitled.app/Capture，默认保存在本机，可逐项移到废纸篓。`.editing` 文件保存原始底图和标注，供以后再次编辑；这些源文件仅保存在本机。复制和导出的 PNG/JPEG/PDF 只包含渲染后的结果，不携带该源文件。插件禁用会取消选区、关闭贴图并结束录屏；历史不会在卸载插件时删除。不要把自己的截图或 API 密钥提交到仓库。

顶部齿轮打开本插件的「截图设置」，包括窗口内快捷键、贴图鼠标操作、保存规则、全局鼠标、滚动方向、录屏选项、本地擦除模型及视觉模型服务配置。应用外观设置位于侧边栏底部。

视觉模型设置位于本插件「截图设置」，填写 HTTPS Chat Completions 接口、支持图像的模型名和 API 密钥；密钥保存在 macOS 钥匙串。每次发送前会要求确认图片和目的服务，服务可能产生费用。没有配置时本地 OCR、文档结构提取、系统翻译和本地译图仍可使用；数学公式识别需要配置服务。

「本地智能擦除」单独提供 [LaMa Core ML](https://huggingface.co/mlboydaisuke/LaMa-CoreML) 的下载与移除入口。用户点击后才下载 187 MiB 模型，安装前校验固定版本的 SHA-256，并在本机编译、缓存。模型及 Apache-2.0 许可位于 `Capture/Models`；图片不上传。本地模型未安装时，纹理修补仍可使用。模型权重不包含在插件 ZIP 或主应用包内。

## 性能与资源

高开销路径包括大图解码与标注、长图拼接、贴图与动图、录屏回放和转码、Vision 识别及可选 Core ML 模型。压缩图片和模型下载大小不等于运行内存。单图上限为 8000 万像素，单份 RGBA 数据就约 305 MiB，掩码、撤销副本和中间结果还会增加峰值。

超长滚动图将封存分段写入磁盘，继续维护活动分段，不将所有段合并为无限大的内存图。分段暂存和历史仍会占用磁盘；需按实际工作流清理保留内容。WebP helper 的消耗与宿主分开观察，贴图数量、动图帧数、并行识别与导出也需计入负载。

按[性能规范](../../docs/PERFORMANCE.md)分别测试普通图片、接近像素上限的大图、跨分段长图、持续录屏、动图导出、多贴图和模型冷 / 暖启动。记录基线、峰值、CPU / GPU、耗时、取消及停用后的状态，并重复启停观察资源趋势。统一截图会话的预算为一个活动会话、一份共享完整快照、一份当前视口渲染和一个在途输出；单图与各屏输入总像素均限制为 8000 万，单份 RGBA 上限约 305 MiB，渲染、蒙版、装饰、PNG 编码和 WindowServer 表面仍会增加峰值。多屏合成后释放各屏原始位图，刷新闭包不保留旧位图；不在每次调选区时重新截图，不增加空闲轮询。范围变化不会复制全图进入撤销栈，标注撤销最多 40 级、单会话最多 10000 标注、单次自由轮廓／笔迹最多 8192 点、最多 64 个选区。取消、停用或退出取消输出、关闭保存面板、解除订阅和关闭控件；正常复制失败或取消保存则保留可重试会话。所有截图控件共享一个弱持有的悬停租约：最多一个 350ms 等待任务、一个悬停期间的本地交互监听和一个不接收点击的提示面板；移出、隐藏、滚动／键盘、取消和关闭清理，非悬停控件不常驻计时器。独立矢量遮罩不再复制全屏像素到另一张位图；入出仅动画其 opacity，成功结束由一个有界租约在淡出后释放表面，取消立即清理。重复截图准入在首个 await／权限检查前完成，拒绝不排队、不新建采集；结束过渡完成前也保持占用。合成图及原生窗口测试覆盖原图扩选、标注锚定、四模式、输入焦点、复制重试、范围内历史源像素与清理；完整真实屏幕采集、接近上限大图、PNG 峰值和 GPU 表面回收不能由这些测试替代。0.12.13 另按用户授权做了本机 2560×1080／1× 实屏采集对比，确认旧版小数坐标选区预览二次缩放的问题，修复与复验记录见开发说明；这不代表真实 Retina 或混合显示器已验收。分段边界、容量拒绝和媒体处理已有功能测试；真实 4K 长时间录制、模型、GPU 与多工作流并发的整机性能峰值尚未完成剖析，不将这些测试视为完整性能验收。

0.12.6 的 4K 合成图原生窗口探针使用优化 Debug（`-O`，非发行 Release），两次独立进程各做十轮：阶段采样最大 footprint 为 178.11 / 177.55 MiB，第十轮关闭后为 56.69 / 51.08 MiB，所有会话弱引用释放；0.12.7 完整工具条再做十轮复核，阶段采样最大 181.34 MiB、第十轮关闭后 53.74 MiB，十个会话弱引用全部释放；0.12.8 共享玻璃与点击保护又做十轮，阶段采样最大 183.55 MiB、第十轮关闭后 55.70 MiB，十个会话弱引用全部释放；0.12.9 原生悬停与紧凑分组工具条复测十轮，阶段采样最大 185.52 MiB、第十轮关闭后 57.50 MiB，十个会话弱引用全部释放；0.12.10 不透明截图／独立矢量遮罩复测十轮（加入入出动画），阶段采样最大 187.24 MiB、第十轮关闭后 60.64 MiB，十个会话弱引用全部释放；0.12.13 源像素视口对齐复测十轮，阶段采样最大 187.41 MiB、第十轮关闭后 59.66 MiB，十个会话弱引用全部释放。包含框架冷启动与缓存，未观察短流程持续累积，但不是完整应用的单插件归因或连续峰值。接近像素上限、实际采集、PNG/GPU 峰值与长期空闲/停用仍未测。Release 测试目标因已有 DEBUG-only 布局钩子引用未能编译，此项没有记作通过；发行应用的签名构建另行验证。

0.12.16 的悬停过渡复用同一矢量遮罩，仅增加一个 CAShapeLayer 描边层和最多两个替换式路径动画；不增加输入查询、动画任务／计时器、队列或另一张全屏源位图，也不在动画每帧重绘冻结截图。停止／移除清除两层动画，复杂轮廓仍沿用原布尔遮罩。十轮 4K 合成图原生窗口、每轮 200 次快速重定向的优化 Debug 探针：冷基线 5.73 MiB，阶段采样最大 206.47 MiB，第十轮关闭后 65.05 MiB，十轮 view／session／shade 弱引用均释放，动画数量始终不超过两个。此负载与旧裁剪／标注探针不同，不作直接性能对比；CA／WindowServer 可分配渲染表面，不能由无额外源位图推断 GPU 零增量。实际 GPU 峰值、长时移动、真实 Retina／混合屏及接近 80MP 的表现未测。

0.12.20 的默认命中画布在普通调整范围时也接收标注事件，但不重复绘制下方已按源像素对齐的图片；空白手势按同一次鼠标按下／拖动／松开交给范围视图，不为悬停逐次扫描所有标注。八组最近选择最多保存八项；图形样式预览只画小矢量图，没有图像解码／模型／缩略图缓存或每按钮计时器。截图会话增加一个按需可见的属性宿主，独立编辑器最多增加一个约几十点高的属性面板，隐藏工具条、关闭、停用／退出一并清理；自定颜色使用真实 22×24 原生色井，关闭其所属界面时释放自有色板状态。新布局和上下文命中已有合成图／原生窗口回归，且通过只捕获自建窗口的工具栏 ROI 核对实际原生图像。最终相同 4K 选区／标注／导出准备负载分别做了两次十轮优化 Debug 探针，冷基线 5.80 / 5.81 MiB，阶段采样最大 183.56 / 182.70 MiB，第十轮释放后 118.64 / 118.34 MiB，所有会话弱引用在原 180ms 检查点释放。原生 UI／色板和 SwiftUI 框架缓存计入整个进程，阶段样本不是连续峰值或单插件占用，也不代表低内存／无泄漏保证。实际 Retina／多屏、长期样式编辑和 GPU 峰值仍未完整验收。

元素检测仅在选区鼠标事件或点击期间执行，不增加空闲轮询或后台队列；常规间隔 80ms，跨元素边界与点击即时更新。只保留当前窗口的一份最小矩形，不缓存 AX 对象或界面文本；树搜索最多访问 32 个节点、向下 12 层，待检查节点最多 32 个，单次查询设 20ms 软预算、每个 AX 引用独立 8ms 消息超时（调度可能使实际耗时更长）。取消、刷新或切换检测模式清理命中状态。命中未变化且无需放大镜/折线预览时不重绘全屏。合成树和原生视图事件测试覆盖稳定性与搜索预算，不代表所有应用的 AX 覆盖率、实际响应时间或 CPU 峰值已测。

## 当前边界

这是依据[公开功能文档](https://pixpin.cn/docs)独立实现的原生 macOS 插件，并非 PixPin 源码的 fork，不包含 PixPin 账号、会员或私有服务。主要截图、标注、贴图、长图、录屏和识别流程已有对应实现，仍不宣称每项偏好、鼠标组合、视觉效果或算法质量与 PixPin 一比一相同。

- 单张图片编辑仍受 8000 万像素上限约束；超长滚动截图使用磁盘分段导出，不会合并为无限大的单张图片。分段间保留重叠，已封存部分不可回滚裁剪。
- 尚未提供兼容 PixPin 的 JavaScript 自定义动作运行时或命令行接口；插件功能通过本项目的原生开发协议注册。
- 本地 OCR、表格和图片译文定位可能识别或排版错误；复杂背景的译图采用周边颜色覆盖，不会精确重建背景。公式识别需要配置模型服务，Word 不保证原文档像素级排版。
- 自动马赛克的相同文字和相似人脸图块联动只用于辅助选择，不具备可靠的人物身份识别。LaMa 对大范围、文字、规则细节或缺少上下文的修补可能产生不自然内容。
- GIF/WebP 无音频，动图导出最长 3 分钟；意外中断恢复仅保证尝试读取已完成的录屏片段。

源码构建支持在本机指定稳定的 Developer ID 签名身份，参见主仓库构建说明。此版本尚未公证。
