# 外设共享 0.12.15：后台光标接管

## 实现及兼容边界

参考 [Oink 0.3.6](https://github.com/oinkvm/oink/tree/c15f2754f0469a25920eb389c97eacbe9b2c529a) 的 macOS 光标接管流程，独立实现于 `SharingNativeCursorSurface.swift`、`SharingCursorCapture.swift`、`SharingInput.swift`。没有拷贝 Oink 的 GPL 代码。Untitled 维持原生插件同进程运行，不增加特权 helper 或 Oink 进程依赖；主窗口可关闭，仍由明确开启的共享会话拥有输入 tap。

- 禁止旧行为的前台激活 fallback。不再隐藏、恢复宿主普通窗口，也不把焦点变化视为接管失效。
- 后台隐藏与解耦完成后，在冻结点以不可键入的面板取得光标外观；session tap 消费一次专用、同代次、同位置事件后，才确认所有权并替换隐藏请求。提交前不发输入。
- 停止、归还、拒绝或过期先撤销转发，再恢复位置及显示。原生面板退出命中测试不依赖 AppKit 等待；系统迟滞时监护不能保证硬实时。普通归还不叠加 hide 计数，不覆盖其他应用已更新的光标样式。
- 单次所有权确认超时且本机清理成功时，保持现有 TLS 连接、键鼠开关和布局，下一次跨屏可重新发起。权限/监听失效、异常指针漂移和清理错误仍使用安全暂停。切换焦点会使旧本机回放作废，不尝试恢复应用前台。
- 保留现有交接 ID 和布局协商、配对密钥、权限检查及急停。同一配对可混用旧版；旧端控制或停放时仍运行旧逻辑。双向采用后台方案需要更新两台的宿主，不要求重装插件。

## 验证范围

Mac16,10 / Apple M4 / 16 GiB / macOS 27.0.1，Command Line Tools 的 Swift 6.4。只读动态符号检查：后台属性、面板标记/顺序/鼠标命中、光标样式和可选区域/显示刷新接口均可解析。这不证明调用成功或实际光标已不可见；macOS 14–26 及未来更新的真机兼容性尚未重新验证。

串行相关回归 134 项 / 7 组通过（共享、布局、权限路由与宿主生命周期）；同步版本号后又运行共享光标和商店兼容 64 项并通过。测试包含 fake 原生调用和本机 TLS 回环；覆盖前台变化不暂停、不确认不转发、超时后同连接重试、急停回调外清理、旧代次和本机重放、单次 hide 责任、失败回收。Xcode 引用与工程 plist 检查通过；本机没有完整 Xcode，未执行 Xcode 构建。

后续真机验收：在 设备 A、设备 B 装同一构建，手动试双向跨屏与快速反向，确认传入的点击/键盘落点正确、切换其他应用不暂停、进入/离开时没有残留箭头；再验全屏、Mission Control、受保护输入、睡眠及急停。单机诊断须先明确同意，结果应由实际视觉确认。不能以成功构建、连通或 fake 回归替代上述验收。

## 本机交付与资源观察

设备 A 已从安装路径启动 **0.12.15 / build 55**；与 `dist/release/Untitled.app` 的二进制一致，Developer ID 指定要求不变，签名验证通过。原版保留私有回退归档。首次只更新 设备 A，未改配对、权限或驱动。当时只读状态显示本机监听就绪、布局已同步、无面板或待恢复资源；对端仍报告键鼠已暂停。没有代用户触发真机接管。

空闲不创建后台光标面板或额外计时器。交接最多一个 16 × 16 pt 面板、一个透明光标、一个确认事件；等待所有权上限 200 ms，复用有界的回放队列。退出接管停止窗口工作；独立监护仅在资源被占用或恢复未完成时运行。没有新增常驻进程。

本机 Release 启动 12–18 秒、保留原共享设置、未发生接管时，间隔 3 秒的整进程样本：CPU 4.5% / 0.9% / 1.2%，RSS 91,488 / 91,840 / 97,920 KiB。不是隔离的插件空闲基线，不归因于后台光标。未测：隔离单插件 footprint 峰值、真实跨屏延迟分布、GPU/I/O、十轮以上回收和长时间使用趋势。

## 后续双机部署

经用户要求，通过 Paseo 将 设备 B（macOS 26.6.2，arm64）从 0.12.0 / build 39 正常退出并更新到与 设备 A 相同的 0.12.15 / build 55。两端深层验签和主程序 SHA-256 均核对一致。设备 A 已是目标版本，未重装；设备 B 保留原应用与配置的私有回退副本，未改配对、权限或驱动。由 设备 A 用原保存的连接端点发起连接。两端均报告已连接、键鼠监听就绪、布局已同步。

后续只读快照显示 设备 A 发出、设备 B 收到输入，但 设备 B 的一次后台光标所有权确认超时（约 215 ms 含清理）；尚无法从现有日志区分窗口命中和事件回执。设备 B 已退回本机，未遗留光标资源或停用共享，TLS 连接仍在。没有注入测试输入或代用户跨屏；双向实机验收仍未通过。
