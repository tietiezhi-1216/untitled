# 剪贴板随共享自动启用 · Untitled 0.12.25 / build 65

- 两台配对 Mac 通过原有「共享」入口连接后，直接复制、粘贴。不再有独立的剪贴板开关或偏好，也不用先切换键鼠。仅新复制的纯文本（≤ 32 KiB）和已复制的 Untitled 截图（PNG ≤ 32 MiB、≤ 2400 万像素）参与同步；其它格式及本机复制路径不变。[截图传输实现](SHARING-0.12.23-CLIPBOARD.md)中关于旧开关的步骤不再适用。
- 本机成功启动共享、认证发现对端并确认版本支持后，自动协商本次连接的授权标识。监听服务、诊断会话、安装插件或打开页面不读取剪贴板；只在双方的会话均就绪时取变更次数作为基线，不读或补发旧内容。0.12.21～0.12.24 端仍按自己的旧版许可逻辑工作；不支持剪贴板的端仍能共享键鼠。
- 原有「共享」关闭、输入安全暂停、锁屏、插件停用或断线都停止同步；恢复时重新取样，不补发期间内容。macOS 拒绝访问时撤销本次剪贴板授权，不暂停键鼠。允许访问后复用现有心跳恢复状态，不另起权限轮询，不改变系统设置。带隐私标记的内容、配对码和接收内容不转发；未标记的秘密无法识别，复制敏感内容前请断开或停止共享。
- 图片仍走独立加密连接；本机粘贴不等远端，不装载/读取用户尚未复制的屏幕内容。资源上限不变，不引入新的常驻任务或队列。
