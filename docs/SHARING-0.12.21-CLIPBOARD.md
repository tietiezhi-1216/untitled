# 双 Mac 剪贴板共享 · Untitled 0.12.21 / build 61

## 使用与范围

1. 两台更新宿主并按原配对连接，无需重装键鼠插件。
2. 在两台的「键鼠共享」页面分别开启「剪贴板共享」，看到「双向同步中」。开启前的剪贴板不发送。
3. 在任一端复制一段新的纯文本，到另一端按 `⌘V`。不要求控制切到那台 Mac。关闭任一端立即停止本端读写；断线或退出后，重连也需要双方重新开启。已同步的文本仍留在接收端剪贴板，关闭不会清除它。

首版只复制单项纯文本表示（UTF-8 ≤ 32 KiB）；不传文件、图片、富文本格式或历史。先检查类型再读取文本，跳过 conceal/transient/auto-generated 等隐私和文件标记；插件复制配对码时标记机密且限本机。不能识别未标记的密码。接收只写本机剪贴板，不模拟粘贴，不转发到 Apple 通用剪贴板。系统访问提示由 macOS 处理；可检测到「始终拒绝」时撤销本端授权，不暂停键鼠。无新增 entitlement、驱动、云服务或配对密钥。

## 协议、生命周期与预算

- 现有 TLS-PSK 连接的可选 Hello 字段仅协商能力，不能代用户开启。两个会话内随机授权 ID 绑定每条文本，撤销、重新授权、断线后拒绝旧帧。旧端仍能连，只忽略新 Hello 字段，不收到新的帧类型。权限/插件生命周期沿用宿主，麦克风与键鼠路由不变。
- 仅双方授权时约每 100 ms 检查一次系统剪贴板变更次数；只在有新内容且发送预算可用时读一次文本。快速连续复制可能合并为最新项。读取中内容或授权变化时不发送。收到的剪贴板不再发回，接收前若发现未取样的本机复制则保留本机内容；跨设备同时复制没有全局先后顺序。关闭、断线、停用、锁屏、睡眠停止工作，无离线队列。
- 单条约 43 KiB 的 JSON/Base64 最大有效帧；网络拥塞时不抢占既有输入发送预算，同一时刻只提交一条等待 Network.framework 接收的剪贴板文本。没有内容持久化、日志、重试队列或后台进程；状态文件只有剪贴板功能状态。Apple 的剪贴板 API 可能先物化原始本地表示，传输限额不等同于限制其他应用的原始剪贴板占用。

## 验证

基于已冻结的 0.12.20 截图源隔离构建。**206 项 / 12 组**串行回归通过，其中 **14 项剪贴板测试**。覆盖实际 TLS 回环双向传输、多字节大小边界、认证后双方开关、旧端兼容、没有启动前/断线补发、撤销后旧帧、无回环、本机新复制优先、权限拒绝及多轮启停释放。测试只使用隔离偏好、fake 剪贴板与 AppKit 私有命名剪贴板，未触碰用户的通用剪贴板。真机操作延迟与长期系统开销未测；本机无完整 Xcode；工程 plist、资源一致性、签名 Release 构建和差异检查通过。

## 双机部署

通过 Paseo 正常退出并安装 0.12.21 / build 61 到 80 和 81；两台与本机 `dist/release/Untitled.app` 的签名指定要求与主程序 SHA-256 均一致，各自保留回退包。原配对自动重连，键鼠监听与布局同步正常，两端均已协商剪贴板能力但开关为关闭。保留 80 已安装的截图更新，不重装插件、不修改系统授权、不代用户开启剪贴板。尚未在两台真机上复制或粘贴用户内容。
