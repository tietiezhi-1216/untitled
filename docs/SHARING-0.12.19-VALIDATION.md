# 外设共享 0.12.19 / build 59：光标外观不再暂停接力

现场：设备 A 和 设备 B 在 0.12.18 的 TLS 连接和布局都正常。设备 B 在返回时完成了系统停放请求，坐标读回偏离约 **0.964 pt**；旧版按 **0.5 pt** 阈值判断失败，关闭了 设备 B 的共享开关。不是断线，也没有证据表明用户动了 设备 B 的鼠标。

## 改动

- [对照 Oink 0.3.6](SHARING-OINK-CODE-REVIEW.md)：正常接力先隐藏、解绑和切换输入路由；漂移只诊断，后台窗口未命中不归还焦点。Untitled 独立实现，不复制 GPL 代码。按协商协议直接进入或按旧版握手，均不等窗口、可见性检查或坐标读回。
- 一份租约只做一次独立的后台外观任务，保留非激活、不可成为 key/main 的透明面板。没有标记移动或显示/再隐藏的修复循环；面板覆盖实际指针及内侧位置时，离开的接收端最多做一次同步移位。没有命中或定位失败，只影响外观，不改变路由/共享；无迟到的面板移动可越过归还。
- 不再以其他进程的合成事件触发暂停，也不把它转发给对端。保留系统授权、安全输入、急停、断线、租约失效和恢复失败的安全处理。保留真实回放顺序和按住状态清理：只在已有事件在途时等待（原 250 ms 上限），去掉额外的 24 ms 坐标等待；原协议与返回位移补偿保留。

## 验证与预算

154 项 / 8 组相关串行回归通过。包含 TLS 回环双向接力和返回、约 0.96 pt 的模拟停放偏差、区域/显示更新不可用、面板未命中、真实冻结或监听失效、拒绝后重试、旧版握手、过期外观任务、急停以及已投递输入的顺序和释放。只使用注入的光标和事件后端，不移动用户的实体鼠标。

不增加空闲轮询；移除活动时持续查询位置和可见性的逻辑。每轮最多一个面板、一个外观任务，已有 200 ms 窗口命中预算不延长（仅外观任务，8 ms 间隔）。状态不保存按键、指针位置或轨迹；可见性位和窗口命中只代表系统报告，不等于屏幕上没有箭头。没有实测两台的物理跨屏延迟、视觉、活动峰值或长时占用；完整 Xcode target 未在仅有命令行工具的本机执行。

## 部署

通过 Paseo 核对空闲后正常退出、安装并在后台启动 设备 A 和 设备 B。两端均运行 **0.12.19 / build 59**；深层严格验签通过，指定要求未变，主程序 SHA-256 与 `dist/release/Untitled.app` 相同。两端以原有配对自动重连，键鼠开关、事件监听和布局均就绪，无待恢复资源。各留 0.12.18 私有回退包。未改配对、Dock、TCC 或驱动；隔离构建保留已交付截图基线，未包含并行中的截图改动。

真机下一步：两台分别以实体鼠标发起往返，分别试普通边与 设备 B 的右侧 Dock 边，观察旧屏是否有箭头和快速反向首笔移动。若仍有顿点，先测真实在途回放的耗时与首帧，不再用坐标阈值和长等待掩盖。
