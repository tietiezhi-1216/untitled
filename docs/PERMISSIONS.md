# 权限与执行规范

Untitled 让用户按需求扩展 macOS 能力。宿主不启用 App Sandbox，原生模块可接入文件、网络、输入、设备、自动化与系统服务。Hardened Runtime、TCC、SIP、文件权限和系统签名要求继续按 macOS 规则工作；取消 App Sandbox 不会自动获得这些权限。

## 当前实现

| 能力 | 状态与入口 |
| --- | --- |
| 屏幕与系统音频录制、辅助功能、输入监控、摄像头、麦克风 | 已接入 HostPermissionCenter / SystemPermissionProvider |
| 文件选择、应用启动、HTTP(S) 链接、系统快捷指令 | 由已有原生动作执行，插件声明相应能力 |
| Finder 定位、系统分享、纯文本剪贴板、本地通知 | 由插件按清单声明调用。文件操作由用户选取目标。通知每次发送前读取 macOS 的授权状态 |
| 蓝牙 | 无线麦通过 HostPermissionCenter 检查蓝牙访问，并在用户操作时连接小米遥控器 |
| 局域网与虚拟麦克风 | 外设共享使用系统网络授权。HAL 驱动由用户单独安装 |
| 目录范围和完全磁盘访问、Apple Events、日历、提醒事项、通讯录、照片图库、定位、USB | 待接入，按具体操作补充 driver、API 和用途声明 |
| 外部可执行插件、内置 agent 执行器、完全接管 | 开发要求如下，当前没有通用运行时和模式开关 |

插件「权限与能力」显示自己的权限用途、系统授权和已声明的动作。文件、剪贴板和通知通过绑定插件身份的客户端调用。用户可针对插件关闭这些能力，配置随插件升级保留。`system.notifications` 通过 UserNotifications 异步核对，恢复后再次检查插件身份、启停和能力开关。

宿主同时只打开一个插件文件选择器。插件停用或卸载会取消相关选择并使进行中的授权检查失效。剪贴板文本上限 16 KiB，通知标题上限 240 字节、正文上限 1 KiB。组件草稿随界面释放，macOS 根据系统设置显示通知。 [Apple 通知授权](https://developer.apple.com/documentation/usernotifications/asking-permission-to-use-notifications)

权限有三层：清单声明宿主能力，宿主检查插件身份与启用状态，macOS 决定受保护资源能否访问。已授权操作无需每次重新授权，执行前仍查询状态。

原生 provider 随宿主编译、同进程运行。broker 能约束经宿主接口发起的操作，不能隔离蓄意绕过接口的原生代码。发布和合并时按真正拥有宿主进程权限的代码审阅。

## 新增系统能力

1. 在 `HostPermissionID` 定义稳定 ID，在 `SystemPermissionProvider` 注册描述、状态查询、请求与系统设置入口。
2. 明确范围与目的，补充真实需要的 Info.plist、entitlement 或 helper；同步命令行打包与 Xcode，保持相同授权行为。
3. 清单声明权限与 reason，业务通过绑定插件身份的客户端调用 `require`。未知或未声明权限不能落到系统 API；关闭的可选能力不要求权限。
4. 状态以系统为准，不保存“永久已授权”。无法准确查询时显示未知或待用户处理，不通过读私密数据猜测授权。
5. 缺少权限时打开对应插件的「权限与能力」。拒绝、限制或撤销后，受保护操作通过该页面提供恢复路径。停止与紧急返回始终可用。

语音听写的实时草稿只更新宿主气泡，不向其他应用送按键。0.13.38+：开始录音只要求麦克风；不读取焦点或剪贴板。只在收到定稿后通过绑定插件的权限客户端静默检查可选的辅助功能授权，再定位当前焦点、原文与选区。能确认可写则向该目标定向插入一次，否则将完整定稿复制到本机剪贴板；写入未确认时也只复制，不向同一或新目标重发。取消、无定稿或成功插入不改剪贴板。自动复制不读取被替换的内容，不安装、选择或移除输入源。0.13.47+ 的 Esc 取消沿用普通 Carbon 注册，仅在听写且尚未投递定稿期间有效；不读取通用键盘事件、不增加权限、不覆盖现有绑定或共享紧急键。

安装、启用和打开页面不代表用户开始录屏、监听、远端控制或安装驱动。已授权动作可按约定触发方式执行，不增加重复确认层。

键鼠共享的后台光标接口（0.12.15+）仅作用于 Untitled 自己的 WindowServer 连接、光标资源和临时面板。不改 TCC、SIP、系统偏好或 entitlement；监听、拦截和模拟事件仍由系统授权与插件客户端限制。遇到安全输入不能通过切换光标后端继续共享。

0.12.25 起剪贴板随用户明确启动、已认证的外设共享会话工作，受已启用插件的 `sharePeripherals` 能力约束，不设单独开关。监听、打开面板或收到对端许可均不会单独开始读取；连接时不发送已有内容。AppKit 负责系统提示和授权，剪贴板读写本身不新增 TCC 或键鼠权限。遇到 macOS「始终拒绝」即停用本轮剪贴板授权，不中断键鼠；恢复授权后重新取样，不补发停用期间内容。

## 宿主快捷键优先模式（0.12.1+）

普通键盘模式使用 Carbon 注册，不需要额外的输入权限。从 0.13.3 起，用户可在菜单栏 Untitled →「快捷键」→「优先使用插件快捷键…」明确开启优先模式（0.12.1–0.13.2 在通用设置）；默认关闭，安装插件或打开设置不代用户开启或请求授权。开启后由宿主固定用途的权限入口检查辅助功能授权，使用一个 session 级 active event tap，只匹配已设置且启用的键盘绑定；不读取文字、不保存输入日志、不把原始键盘事件交给插件。active filter 需要辅助功能，不能将 passive listen-only 的输入监控要求混为一谈。

从 0.13.29 起，不开启键盘优先模式也能绑定全局鼠标侧键。宿主仅在有活动侧键绑定时订阅 otherMouse 的按下、松开及拖动，不因此订阅键盘、移动或滚轮。只消费匹配的物理侧键及其配对，不把鼠标位置、原始事件或其他应用的文字交给插件。辅助功能未授权时显示该条绑定的恢复入口，不影响普通键盘注册、不自动请求授权。暂停、重绑、卸载和退出释放监听/按住动作；和优先键盘通道分开计数，侧键最多 29 个物理键位，有界队列 256 个转换，无按下时不轮询。

0.13.31 起，绑定独立右 ⌘；0.13.32 起也支持独立右 ⌃。两者只订阅 flagsChanged，不订阅普通键盘按下/松开。宿主放行所有修饰键事件，仅在候选手势期间检查物理键位和键鼠事件距今时间；不读取按键内容。按住类动作有 200 ms 判定窗口，持键期间每 100 ms 检查组合、失权和遗漏的松开；空闲不轮询。检测到复制、粘贴、其他修饰键或共享让行时不启动；已经启动时取消。独立修饰键不需要开启键盘优先模式，缺少辅助功能授权仅影响对应注册，不弹授权、不代开其他监听。

这是宿主的命令触发设置，不给插件增加输入访问权限，不改插件清单或用户绑定。触发仍绑定当前插件 ID、命令 ID、配置代次和启用状态；截图、听写、共享等业务仍走各自声明受限的 `PluginPermissionClient`。宿主请求有独立来源，不伪装成插件，不提供任意权限绕过接口。

优先模式对匹配的按下、重复和松开尝试阻止下游接收，不修改系统快捷键。安全输入、更早或后来插入的过滤器、系统保留行为可能限制优先级，不能保证抢占所有系统功能。监听创建失败、被系统停用或权限失效时释放逻辑按住动作并明确显示普通注册回退及恢复入口，不循环抢占。可在菜单栏 Untitled →「快捷键」暂停或恢复插件快捷键；录制快捷键、停用或卸载插件会取消对应动作。普通重绑保留旧物理按键的短暂排空，权限丢失、超时或退出时不能保证系统侧的按键配对，不通过注入输入掩盖故障。

0.12.14 起，临时回退不再只等授权值变化：返回应用、解锁或唤醒会在授权且安全输入已结束时恢复失败路由，不重建健康监听。失败期间最多一个恢复任务，按 0.25 / 0.5 / 1 / 2 / 4 / 8 / 16 / 30 秒依次等待，单轮最多八次就绪检查、累计计划等待 61.75 秒（不含系统调用与调度延迟）；安全输入期间不创建监听，缺少授权时不调度此任务、不弹授权。预算耗尽后停止等待，后续生命周期事件或手动重试可开始新轮次，因此不是对任意时长安全输入结束的即时恢复保证。成功、暂停、快捷键录制、无有效绑定、关闭优先模式及退出均取消；代次保护阻止旧任务重绑。插件操作页显示实际回退原因；菜单栏「快捷键」在发生回退时提供授权或重试的入口。普通注册也失败时不隐藏其错误；实际注册成功后同步撤掉对应的“操作已保存，但快捷键未生效”旧通知，不关闭其他输出／保存错误。恢复不修改绑定、启停或偏好，不注入按键。

键鼠共享入口复用同一匹配状态机和物理按键记账，避免两个 event tap 的创建顺序决定行为。交接、远端控制、停放或回放未完成时，普通插件快捷键让行共享输入；共享紧急 Esc/K 路径及显式停止动作保留，切换到远端的快捷键等待松开且取消时不发起交接。合成输入及共享回放不触发本地插件快捷键。

预算为一个优先 tap、128 个物理键位状态、256 个有序待处理转换；普通输入只做键码/修饰键匹配。业务调用在 tap 回调外有界派发，健康或停用状态无空闲轮询；失败恢复仅限上述有界任务。仅按键未完成时每 250 ms 检查授权、安全输入和丢失松开，迟到松开保护最多 1 秒。fake 生命周期测试不能代替实体按键抢占、双机或长期性能验收。

0.13.32 通过隔离驱动验证了右 ⌃ 单独按住/松开、右 ⌃ 组合键取消、侧键拖动事件录制，以及录制时不触发。0.13.29 通过隔离驱动验证了侧键按住听写、松开定稿、单键切换、录制时不触发、缺授权仅影响侧键及授权恢复。普通 Carbon 的 F20 注册与本进程内按下/松开分发已验证；未向用户输入框发事件或打开麦克风。优化编译的独立匹配器处理 20 万个未绑定侧键的模拟按下/松开用时 10.05 ms；11 次启停均回收，没有触发操作。这里测的是事件匹配，不代表原生鼠标驱动、系统分发耗时或宿主整体 CPU/内存峰值。

## 完全接管：新增运行时的交付要求

“完全接管”是用户把明确范围内的执行权委托给受信任插件或 agent。当前尚未实现本节模式，系统授权仍以 macOS 为准。

| 范围 | 实现要求 |
| --- | --- |
| 启用 | 显示执行者、工具范围、数据范围与有效期，由用户主动选择；允许在已授权范围内持续工作 |
| 身份 | 绑定插件 ID、代码身份或包校验值；新 fork、执行器或权限扩展不静默继承旧授权 |
| 工具 | 文件、进程、Shell、网络与跨应用控制有真实接口、结果和错误，不以开关文案代替运行时 |
| 范围 | 可选工作区、目录或用户明确授予的更广范围；独立 helper / XPC 按其真实身份处理权限 |
| 停止 | 有直接可操作的停止入口，取消任务、结束子进程、释放监听和连接，允许用户夺回控制 |
| 撤销 | 禁用、卸载、授权失效、退出和到期结束委托，不在重启后恢复被撤销任务 |
| 可检查性 | 记录操作来源、结果和错误供用户检查；普通日志不含密钥、配对信息与受保护内容 |
| 升级 | 保留配置；新增工具、范围扩展、执行身份变化需要可见的授权更新，普通修复不重置选择 |

代码执行协议、权限控制、安装升级、异常清理、界面与拒绝路径完成后，才能写为“支持”。现有声明式 ZIP 仍只允许清单与说明，不执行安装脚本。

## 系统依据

Apple 说明了[文件与完全磁盘访问、辅助功能、自动化的用户授权](https://support.apple.com/guide/security/secddd1d86a6/web)。媒体权限采用 [AVCaptureDevice 授权状态](https://developer.apple.com/documentation/avfoundation/avcapturedevice/authorizationstatus(for:))，辅助功能使用 [AXIsProcessTrustedWithOptions](https://developer.apple.com/documentation/applicationservices/1459186-axisprocesstrustedwithoptions)，输入监控使用 [CGRequestListenEventAccess](https://developer.apple.com/documentation/coregraphics/cgrequestlisteneventaccess())。系统状态不能由清单或模式开关替代。
